# Logic 101: Validity vs. Truth

Logic is the art of not being fooled. The first thing you need to know is the difference between a "Valid" argument and a "True" argument.

## The Difference
* **True:** Matches reality. (e.g., "Grass is green.")
* **Valid:** The conclusion follows from the premises.

**A Valid but False Argument:**
1. All toasters are time machines.
2. Dave is a toaster.
3. Therefore, Dave is a time machine.

The logic is perfect (A + B = C). But the premise is nonsense. To win an argument, you need both Validity AND Truth.
