# Philosophy 101

A beginner-friendly philosophy library for curious readers. Each volume offers short, plain-language introductions to big ideas, familiar examples, and questions to think about for yourself.

Read the library at [melvinvarghese.github.io/philosophy-101](https://melvinvarghese.github.io/philosophy-101/).

## How to Navigate

The library is divided into **10 volumes**:

* [**Vol 1: The Toolbox**](https://melvinvarghese.github.io/philosophy-101/volumes/the-toolbox/) — Start here. Logic, arguing, and how to think.
* [**Vol 2: Metaphysics**](https://melvinvarghese.github.io/philosophy-101/volumes/metaphysics/) — The weird stuff. God, simulations, and reality.
* [**Vol 3: Epistemology**](https://melvinvarghese.github.io/philosophy-101/volumes/epistemology/) — Knowledge. Truth, science, and skepticism.
* [**Vol 4: The Mind**](https://melvinvarghese.github.io/philosophy-101/volumes/the-mind/) — Consciousness, AI, and the Self.
* [**Vol 5: Ethics**](https://melvinvarghese.github.io/philosophy-101/volumes/ethics/) — Right, wrong, and the gray areas.
* [**Vol 6: Politics**](https://melvinvarghese.github.io/philosophy-101/volumes/politics/) — Power, justice, and freedom.
* [**Vol 7: Aesthetics**](https://melvinvarghese.github.io/philosophy-101/volumes/aesthetics/) — Art, beauty, and horror.
* [**Vol 8: The Ancients**](https://melvinvarghese.github.io/philosophy-101/volumes/the-ancients/) — Where it all began (Greeks, Romans, etc.).
* [**Vol 9: The Moderns**](https://melvinvarghese.github.io/philosophy-101/volumes/the-moderns/) — The thinkers who built the modern world.
* [**Vol 10: The Search for Meaning**](https://melvinvarghese.github.io/philosophy-101/volumes/meaning-of-life/) — Existentialism, Nihilism, and Eastern Wisdom.

## A Note on Reading

Don't try to read this cover to cover. Treat it like a buffet.

* Feeling lost? Go to **Vol 10**.
* Feeling angry at the news? Go to **Vol 6**.
* Feeling confused about reality? Go to **Vol 2**.

Enjoy the journey.

## Preview locally

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve --baseurl /philosophy-101
```

Open `http://127.0.0.1:4000/philosophy-101/`. To build the static site without starting the preview server, run `bundle exec jekyll build`.
